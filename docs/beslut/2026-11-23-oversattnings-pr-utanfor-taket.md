# Översättnings-PR utanför taket på fyra (2026-11-23)

**Beslut (DasKrokodil, 2026-11-23).** Pull requests i issues med etiketten `översättning` räknas inte mot de fyra öppna pull requests per person, men har ett eget tak på **högst 8 öppna översättnings-PR per person**. Då kan de åtta pågående översättningsomgångarna (en per språk och period) öppnas direkt i stället för att vänta på gren.

Reglerna i övrigt är oförändrade: omgångar på ungefär 100–150 texter, `tools/dela_data.py` och `tools/oversattning.py` körda, ombasering på `main` före PR, genererade filer räknas inte som krock, och översättningen ändrar aldrig fakta. Översättnings-PR som också rör kod, data utöver texterna eller CSS räknas som vanligt mot de fyra. Ersätter undantaget 2026-11-12 (bygg på gren tills en plats är ledig). Följer mönstret i beslutet 2026-11-21 (bild-PR utanför taket). Prövas efter en vecka: sänks om översättnings-PR väntar mer än två dygn på ihopslagning eller ofta måste ombaseras.
