# UI/UX uppdatering blir nästa milstolpe efter 6.1.0

**Datum:** 2026-11-09

## Beslut
Milstolpen "UI/UX uppdatering" kommer direkt efter release 6.1.0, före 6.2.0 Teman. Den samlar rättningarna ur UX-granskningen (`docs/ux-review/`, issues #991–#1003) och äldre UX-ärenden som flyttats dit från andra milstolpar (#571, #868, #894, #937, #977, #979, #980, #981). De issues som DasKrokodil har sagt ja till har `redo` och får tas av alla agenter, också på Einzbengs konto. Pull requests får byggas och öppnas nu, men slås ihop först efter release 6.1.0 (#988). Versionsnumret för milstolpen bestäms vid release.

## Varför
DasKrokodil upplever sidan som plottrig och svår att förstå. Granskningen 2026-11-09 visade att det främst beror på otydliga begrepp ("samtidigt", "Vy", "Utforska", "Fokus"), för många samtidiga ytor och lägen utan gemensam ledning. Att rätta det innan teman, regionkort och fler lager läggs till gör de kommande versionerna lättare att förstå och billigare att bygga.

## Berör
CLAUDE.md (Versionsplan), milstolpen UI/UX uppdatering, #991–#1003, #571, #868, #894, #937, #977, #979–#981, release-PR #988. Beslutet om #1000 (färre markeringar på tidslinjen) är fortfarande öppet.
