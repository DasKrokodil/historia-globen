# Rekommendation i varje beslutsissue, och DasKrokodil i stället för namn

**Datum:** 2026-11-08

## Beslut
1. **Rekommendationer:** varje issue som kräver beslut (`beslut-krävs`, eller som ställer frågor till ägaren) ska ha ett avsnitt "Rekommendation till DasKrokodil" med vad som rekommenderas, varför, och ett förslag på svar för varje fråga. Det gäller nya issues, och äldre issues med `beslut-krävs` får en rekommendation som kommentar. Rekommendationen är ett förslag; beslutet fattas av ägaren.
2. **Namn:** i ny text som syns på GitHub skrivs ägaren som DasKrokodil, inte med förnamn. Äldre text ersätts inte nu.

## Varför
Ägaren är projektledare och ska kunna läsa en rekommendation och svara ja eller nej, i stället för att själv formulera alternativen. Andra kan läsa projektet på GitHub, och användarnamnet räcker som namn.
