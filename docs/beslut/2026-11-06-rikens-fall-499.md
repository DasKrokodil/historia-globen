# Rikens fall som turer med status per steg (#499)

**Datum:** 2026-11-06 (pilot enligt Rikards beslut i #499 den 2026-11-03; format enligt #247 alternativ A och #500)

## Beslut
Piloten "Hur föll det?" byggs som turer i `data/turer/`, inte som ett nytt läge. En tur kan ha `empire` (riket den följer), och rikets faktaruta får då knappen "Följ fallet". Ett steg kan ha `status` med samma ord som slutkortet: belagt, omtvistat eller okänt. Kapitlen (`chapter`) ersätter fasta faser, så att ett förlopp kan sakna till exempel "tidiga tecken". Tre turer: Västromerska riket, Hanriket och Songhairiket. Rikard valde Songhai i stället för mayastäderna den 2026-11-06, eftersom mayastäderna inte var ett enda rike med ett enda slut; de sparas till #531. Fler riken efter utvärderingen finns i #531.

## Varför
Turerna och slutkortets tre rubriker finns redan, så piloten behöver bara två valfria fält. Codex rekommenderade att pröva formatet i rikets egen Fokus-berättelse före ett fristående läge, och att perspektivet "vanliga människor" bara visas när en källa säger något.
