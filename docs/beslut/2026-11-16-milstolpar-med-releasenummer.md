# Milstolpar med releasenummer och färre spår

2026-11-16

**Beslut (DasKrokodil, 2026-11-16):** Milstolparna i GitHub döps om så att namnet börjar med den release de tillhör, och
spåren slås ihop. Prioriteringen just nu är att bli klar med riken, täckningen, symbolerna och UI/UX.

| Milstolpe efter ändringen | Tidigare | Release |
|---|---|---|
| Version 6.5.0: Riken: global täckning | Riken: global täckning | 6.5.0 |
| Version 6.5.0: Täckning: händelser och balans | Täckning: händelser och balans | 6.5.0 |
| Version 6.5.0: Riken: symboler och flaggor | Riken: symboler och flaggor | 6.5.0 |

Oförändrade: Version 7.2, 8 och 9 och Idébank (inte planerat). "Rymden" heter nu "Rymden (inte planerat)".

**Hur:** alla issues, öppna och stängda, flyttades till den sammanslagna milstolpen och de tomma milstolparna stängdes
(inte raderade). Release v6.4.0 publicerades 2026-11-15; nästa release är v6.5.0.

**Motivering:** Det ska synas på namnet vilka milstolpar som hör till vilken release. Fyra spår i en release och en
tydlig ordning efter den gör det lättare att se när 6.5.0 är klar. Milstolpar som väntar på beslut eller idéer får
"ingen release" eller "inte planerat" i namnet. Namnbyte och flytt av issues sker enligt beslutet 2026-11-12
(backlog review vid release).
