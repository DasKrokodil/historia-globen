# Rapportens sista rad om nya issues, och AI-illustrationer med ChatGPT

2026-11-16

**Beslut (DasKrokodil):**
1. **Rapportens slut ska säga om nya issues skapades.** Raden "Nya issues: #…" läses som att det inte finns mer att göra när den saknar nummer. Rapporten från Claude Code har därför alltid två rader sist: `Nya issues skapade: ja, #… / nej (inga nya skapades i den här körningen)` och `Kvar att ta: N issues med redo (#…) / inga`. "Nej" betyder bara att körningen inte skapade något nytt och aldrig att arbetet är slut.
2. **AI-illustrationer görs av en människa i ChatGPT** (DasKrokodil eller Andreas) enligt docs/bilder-ai-illustrationer.md. Ett issue som väntar på det säger det i klartext, vem som ska göra vad, och hur.

**Motivering:** En sista rad utan innehåll ser ut som "klart", fast det kan finnas `redo`-issues kvar eller en bild som väntar på en människa. Ett tydligt steg-för-steg gör att Andreas kan ta en bildissue utan att behöva fråga.
