# Milstolpar att skapa

Claude Code har inget verktyg för att skapa milstolpar i GitHub. Skapa dem under **Issues → Milestones → New milestone**, i den här ordningen, med titel och beskrivning exakt som nedan.

Alla issues och etiketter finns redan. När milstolparna finns kan Claude koppla issuena till dem. Säg bara till. Varje issue har också en rad "Milstolpe: …" i beskrivningen, så kopplingen syns även innan dess.
