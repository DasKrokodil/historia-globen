# Skärmbilder till issues

Den här grenen innehåller bara skärmbilder som länkas från issues i Historia-globen. Den har ingen historia från `main` och slås aldrig ihop med den. Radera inte grenen: länkarna i issues bryts då.

Regler (beslut 2026-11-14, docs/beslut/2026-11-14-skarmbilder-i-issues.md på main):
- En mapp per issue: `issue-<N>/`, till exempel `issue-1234/fore.webp`, `issue-1234/efter.webp`, `issue-1234/forslag-a.webp`.
- WebP, högst cirka 150 kB per bild, inga personuppgifter.
- Länka i issuet: `![beskrivning](https://raw.githubusercontent.com/DasKrokodil/historia-globen/skarmbilder/issue-<N>/<fil>.webp)`
- Bara skärmbilder här. Ingen kod och inga data.
