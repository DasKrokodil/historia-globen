# Ett namn på platskortets kartknapp och kartvy (#1948)

Chromium, svenska, 1280 × 800 och 400 × 800, år 1800. Före: main ce3d99a0. Efter: codex/issue-1948-kartans-namn a57bcbad. Samma lokala three.js-version, blockerade Google Fonts och reducerad rörelse i båda jämförelserna.

Knappen heter Visa på kartan i alla tre kartvägar efter ändringen. De två regionvyerna visar Platsens karta; vanlig Platt karta behåller sin vy. Varje fall visar både kortets knapp och den öppnade kartan.
